# Privacy and security reports

Do not attach pairing records, private keys, Apple IDs, serial numbers, UDIDs, ECIDs, personal device names or real location history to public issues.

The device bridge uses anonymous session-local tokens. Raw exception text and dependency logs are suppressed. Pairing credentials managed by Apple and pymobiledevice3 remain in the local user profile and must not be included in archives.

Use GitHub private security reporting if enabled. Otherwise describe the affected component without including secrets in a public issue.
